# SecretVisuals Updates

Публичный репозиторий только для манифеста обновлений и ссылок на релизы лаунчера SecretVisuals. Не размещайте здесь исходный код лаунчера, лицензионные базы, ADMIN-коды, токены или приватные ключи.

## Как публиковать обновление

1. Соберите Windows-установщик проекта с версией `X.Y.Z` в `package.json`.
2. Создайте GitHub Release с тегом `vX.Y.Z`.
3. Прикрепите установщик с точным именем `SecretVisuals-Setup-X.Y.Z.exe`.
4. После публикации GitHub Actions автоматически вычислит SHA-256 файла и обновит `latest.json` в `main`.

Лаунчер проверяет манифест по адресу `https://raw.githubusercontent.com/goblocksixd-ops/SecretVisuals-Updates/main/latest.json`. Если сборка лаунчера старше версии в манифесте, он предложит обновление и проверит SHA-256 до запуска установщика.
